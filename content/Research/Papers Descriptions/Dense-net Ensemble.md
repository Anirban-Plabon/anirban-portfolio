## 🧩 *Multi-class Brain Tumor Classification with DenseNet-Based Deep Learning Features and Ensemble of Machine Learning Approaches*

**Conference:** International Conference on Big Data, IoT and Machine Learning (BIM 2023)

**DOI:** [10.1007/978-981-99-8937-9_38](https://link.springer.com/chapter/10.1007/978-981-99-8937-9_38)

**Authors:** Shakil Mahmud Shuvo, Md. Farukuzzaman Faruk, Azmain Yakin Srizon, Tahsen Islam Sajon, S.M. Mahedy Hasan, Anirban Barai, A.F.M. Minhazur Rahman, Md. Al Mamun

---

### 📄 Summary

This study proposes a **DenseNet-based feature extraction model** combined with an **ensemble of machine learning classifiers** (Random Forest, SVM, XGBoost) for **multi-class brain tumor classification**.
The system utilizes deep CNN feature maps as input to traditional ML classifiers, yielding enhanced interpretability and robustness.

---

### 🧠 Highlights

* **Hybrid Approach:** Combines CNN feature extraction with classical ML for improved generalization.
* **Dataset:** MRI brain scans categorized into multiple tumor types.
* **Core Model:** DenseNet backbone for deep feature learning.
* **Ensemble Layer:** SVM + RF + XGBoost voting ensemble.
* **Performance:** Outperformed standalone CNNs in accuracy and F1-score across multiple datasets.

---

### ⚙️ Technical Insights

* Feature fusion layer aggregates DenseNet outputs before passing to ensemble classifiers.
* Ensemble decision rule ensures stability against overfitting.
* Evaluated on multi-class datasets with high inter-class variance.

---

### 📈 Outcome

The hybrid ensemble achieved **state-of-the-art results** with improved generalization, showing that **deep features + ensemble ML** can outperform end-to-end CNNs for limited medical imaging data.
